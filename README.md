# Підпис зображень за допомогою RSA (4096 біт)
Цей проєкт реалізує цифровий підпис зображень у форматі PNG за допомогою RSA-ключів (4096 біт) із приховуванням підпису в метаданих зображення (тег PNG tEXt).

## Функціонал
- Генерація ключової пари RSA (4096 біт) через OpenSSL.
- Створення підпису зображення за допомогою приватного ключа.
- Приховування підпису у метаданих зображення.
- Перевірка підпису з використанням публічного ключа.
- Повна підтримка командного рядка.

## Використання
Генерація ключів
```
python rsa_sign_image.py gen-keys
```
Результат: створюються файли private.pem і public.pem

## Підпис зображення
```
python rsa_sign_image.py sign image.png private.pem
```
Результат: створюється файл signed_image.png (де image.png — вхідний файл)

## Перевірка підпису
```
python rsa_sign_image.py verify signed_image.png public.pem
```
Результат: виводиться повідомлення про успішну або невдалу перевірку.

## Як це працює:
Підпис:

1. Зображення відкривається та перетворюється в байтовий потік.
2. Обчислюється SHA-256 геш.
3. Підпис створюється з використанням PKCS#1 v1.5 (через pkcs1_15).
4. Підпис вставляється як текстове поле Signature у PNG метадані.

Перевірка:
1. Витягується підпис із метаданих.
2. Повторно обчислюється геш зображення (без метаданих).
3. Підпис перевіряється з використанням відкритого ключа.

- Виявлення несанкціонованих змін у графічних архівах або медіа.
